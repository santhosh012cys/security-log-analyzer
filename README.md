# 🔐 Security Log Analyzer

A Python-based cybersecurity project that analyzes login logs,
detects repeated failed login attempts, identifies suspicious IP
addresses, and generates a security report.

## 🚀 Features

- Analyzes security login logs
- Counts successful login attempts
- Detects failed login attempts
- Identifies suspicious IP addresses
- Assigns risk levels
- Generates CSV security reports

## 🛠️ Technologies Used

- Python 3
- CSV
- Collections
- File Handling

## 📂 Project Structure

security-log-analyzer/
│
├── log_analyzer.py
├── security.log

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

python log_analyzer.py

## 📊 Risk Detection

| Failed Attempts | Risk Level |
|---|---|
| 1-2 | LOW |
| 3-4 | MEDIUM |
| 5+ | HIGH |
